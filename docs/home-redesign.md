# 보험계산기 홈 개편

## 목적과 범위

2026-09-07. 주식·머니·연봉·세금계산기의 최근 홈에서 상황별 시작점, 대표 도구, 계산 순서, 관련 읽을거리 구조를 참고했다. 보험에서는 병원비 확인, 해지·유지 비교, 가족 보장 점검으로 재구성했다. 보험의 개인별 조건이 달라 대표 지급액이나 임의의 보험료 비교표는 두지 않는다.

홈 페이지와 홈 탐색 데이터만 변경한다. 기존 11개 계산기 URL, 계산 화면, 엔진, 규칙, HOLD 4건은 변경하지 않는다. 기존 사용자 파일은 커밋에 포함하지 않는다.

## 구성

- 소개와 준비 자료: 영수증·보험증권·해지환급금·보장 현황을 안내한다.
- 상황별 시작: 실손은 특정 세대를 기본 추천하지 않고 세대 선택으로 연결한다.
- 실손 세대 선택: 현재 적용 약관 확인, 1세대 미지원 표시.
- 해지·유지 순서: 환급금 → 남은 보험료 → 비교. 보장 상실과 재가입 조건을 별도로 확인하도록 안내하며 입력값 자동 전달은 약속하지 않는다.
- 전체 계산기: 기존 레지스트리 기준 4개 분류, 모든 계산기 유지.
- 가이드와 FAQ: 발행된 가이드만 연결, 참고용 결과와 계약 자동 조회 미지원 안내.

## 유지보수

계산기 이름·설명의 정본은 `src/lib/site.ts`, 홈의 배치·분류는 `src/lib/home.ts`다. 계산기 추가 시 홈 분류에도 포함해야 하며 `tests/homeNavigation.test.ts`가 누락·중복을 검출한다. 가이드 발행 상태 변경 시 홈 연결도 검사한다. 상품·정책 변경은 기존 보험 규칙 검토 절차를 따르며 홈에서 별도 계산 상수를 관리하지 않는다.

홈 검사는 실제 서버 렌더 결과의 링크, 앵커, H1, 등록 계산기 전체 포함 여부, 발행 가이드, 기존 허브와 해지 순서를 확인한다. 배포 전 전체 테스트·타입·린트·빌드와 데스크톱/모바일 화면을 확인한다.

## 검증 기록

- 전체 81개 테스트 파일 통과(기존 80개 + 홈 탐색 검사).
- TypeScript 및 ESLint 통과, 프로덕션 빌드 성공.
- 데스크톱과 390px 모바일 미리보기 확인. 모바일 문서 너비 390px로 가로 넘침 없음.
- 상황별 실손 버튼의 세대 선택 앵커 이동 확인. 홈 검사로 전체 계산기·공개 가이드·허브의 내부 경로 존재와 앵커를 검증.
- 개발 서버가 생성한 지침 파일은 제거하고, 자동 변경된 타입 참조 파일은 프로덕션 빌드로 원래 상태에 복구됨. 기존 `Claude outputs/`는 미추적 사용자 자료로 그대로 보존.
